# Navegue Seguro - Guia de Segurança Digital 

Uma *landing page* simples, intuitiva e com código limpo, desenvolvida especificamente para o público da terceira idade. O objetivo principal deste projeto é ensinar boas práticas de segurança na internet e ajudar os utilizadores a evitarem burlas (golpes) no telemóvel e no computador.

## Funcionalidades

* **Foco na Acessibilidade:** Interface com alto contraste e sem distrações visuais.
* **Ajuste de Texto:** Botões para aumentar (A+) e diminuir (A-) o tamanho da letra, facilitando a leitura.
* **Dicas Práticas:** Informações diretas sobre como identificar mensagens falsas e links perigosos.
* **Teste Interativo:** Um pequeno questionário prático para testar os conhecimentos de segurança do utilizador.

## Tecnologias Utilizadas

Este projeto foi construído de forma simples e direta, sem recurso a bibliotecas externas complexas:
* **HTML5:** Estruturação semântica da página.
* **CSS3:** Estilização com variáveis para facilitar a alteração de cores e tamanhos.
* **JavaScript:** Lógica para a funcionalidade de acessibilidade (tamanho do texto) e validação do teste de segurança.

## Como aceder ao projeto

**Visualizar Online:**
Pode aceder à versão final do site através do GitHub Pages:
https://devmarinhou.github.io/Navegue-Seguro/

**Executar Localmente (no seu computador):**
1. Faça o *download* (descarregue) ou clone este repositório.
2. Abra a pasta do projeto.
3. Dê um duplo clique no ficheiro `index.html` para abri-lo em qualquer navegador web (Chrome, Edge, Firefox, etc.). Não é necessária nenhuma instalação adicional.

## Estrutura de Ficheiros

* `index.html` - Contém toda a estrutura e conteúdo da página.
* `style.css` - Contém as regras de visualização e acessibilidade.
* `script.js` - Contém as funções interativas do site.
