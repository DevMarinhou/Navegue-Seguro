# Política de Privacidade e Segurança

Bem-vindo(a) ao **Navegue Seguro**. A sua segurança e privacidade são a nossa maior prioridade. 

Criamos esta página para ajudar você a se proteger na internet. Para que você navegue com total tranquilidade por aqui, preparamos este documento simples para explicar como funcionamos.

---

## 1. Não coletamos seus dados pessoais
O site **Navegue Seguro** é uma página puramente educativa. Nós **NÃO** pedimos, **NÃO** coletamos e **NÃO** guardamos nenhuma informação sua. 
* Não temos formulários de cadastro.
* Não pedimos seu nome, CPF, telefone ou e-mail.
* Não solicitamos senhas ou dados bancários.

## 2. Não usamos Cookies de rastreamento
Sabe aqueles "cookies" que outros sites usam para seguir o que você faz na internet e depois mostrar propagandas? Nós não usamos isso. O nosso site não rastreia a sua navegação e não exibe anúncios. 

*(Nota técnica: O site é hospedado de forma segura através do GitHub Pages, que pode registrar dados básicos de rede, como o endereço IP, apenas para manter o site no ar e seguro contra ataques cibernéticos, mas isso não é usado para identificar você pessoalmente).*

## 3. Nosso compromisso de segurança
Como o nosso objetivo é combater golpes, deixamos claro o nosso compromisso com você:
* O **Navegue Seguro** NUNCA enviará mensagens no seu WhatsApp.
* NUNCA ligaremos para você.
* NUNCA pediremos transferências via PIX, boletos ou dinheiro.
* NUNCA enviaremos links por SMS ou e-mail pedindo para você atualizar dados.

Se alguém entrar em contato com você usando o nome "Navegue Seguro" pedindo qualquer uma dessas coisas, **é golpe**. Bloqueie e denuncie!

## 4. Links para outros sites
Podemos colocar links que levam para sites oficiais (como o PROCON de Tocantins ou a Polícia Civil). Quando você clicar nesses links e sair da nossa página, recomendamos que preste atenção, pois cada site tem as suas próprias regras de segurança.

## 5. Atualizações desta política
Se no futuro precisarmos mudar alguma coisa nesta política, o texto será atualizado diretamente nesta página. Mas fique tranquilo(a): a regra de nunca pedir seus dados ou dinheiro jamais mudará.
